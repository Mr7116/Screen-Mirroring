How to turn on USB debugging
  1. Open Settings → About phone and tap Build number 7 times.
  2. Go back to Settings → System → Developer options.
  3. Turn on USB debugging (and USB debugging (security settings) on Xiaomi phones, so the mouse can control it).
  4. Plug in the cable and tap Allow when the phone asks.

How to get the iPhone app

The app's source is in the ios-sender folder of this program. It is built once on a Mac with Xcode (free Apple ID is enough for your own iPhone): open the folder, run xcodegen, open the project, choose your iPhone and press Run. Its README has the steps.
